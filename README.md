# AI Avatar Web3 Landing Page

A Next.js landing page for an AI avatar platform with internationalization support.

## Prerequisites

- **Node.js** 18.0.0 or higher
- **Yarn** (recommended) or npm

## Getting Started

1. **Install dependencies:**
   ```bash
   yarn install
   # or
   npm install
   ```

2. **Run the development server:**
   ```bash
   yarn dev
   # or
   npm run dev
   ```

3. **Open your browser:**
   Navigate to [http://localhost:3030](http://localhost:3030) to view the application.

## Available Scripts

- `yarn dev` - Start development server
- `yarn build` - Build for production
- `yarn start` - Start production server
- `yarn lint` - Run ESLint with auto-fix
- `yarn check-types` - Run TypeScript strict type checking

## Features

- **Internationalization**: Support for English, Japanese, Chinese (Simplified), and Chinese (Traditional)
- **Responsive Design**: Mobile-first approach with Tailwind CSS
- **TypeScript**: Full type safety
- **SVG Support**: Custom SVG components with webpack configuration
- **UI Components**: Radix UI components with custom styling

## Building for Production

```bash
yarn build
yarn start
```

This will create an optimized production build and start the server.
